# google-drive-server

Сервис для сохранения и просмотра видео из папок Google Drive, к которым у владельца аккаунта
есть доступ, но которые он не контролирует (например, записи лекций Zoom, расшаренные
преподавателем).

## Что делает

- Раз в час проверяет указанные папки Google Drive (вместе с подпапками) и скачивает на сервер
  новые и изменённые файлы.
- Хранит собственную копию: если файл или папку удалят в Drive или у аккаунта отберут доступ,
  уже скачанные файлы остаются на сервере. При изменении файла в Drive предыдущая версия
  сохраняется рядом.
- Отдаёт скачанные видео через веб-интерфейс: список от новых к старым, просмотр с перемоткой
  и переключением между видео. Изменять или удалять файлы через веб нельзя.

## Запуск

```bash
cp .env.example .env   # ID папок Google Drive через запятую и OAuth-клиент (Desktop app)
set -a; source .env; set +a
sbt "run auth"         # один раз: вход в Google, refresh token сохраняется в БД
sbt run
```

Остальные настройки — в `src/main/resources/application.conf`. Деплой на сервер — [deploy/README.md](deploy/README.md).
